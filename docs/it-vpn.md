# Настройка VPN
Для удаленной работы используйте корпоративный VPN.
Инструкция:
1. Скачайте клиент с https://vpn.company.local/download.
2. Введите свой корпоративный логин (без @company.ru) и пароль от почты.
3. Выберите сервер "Moscow-1" или "Moscow-2".
4. При проблемах со входом — обратитесь в IT-отдел через тикет (категория: access).
